- **方法**：自研 PO 面元法单站 RCS 求解器（Crispin–Maffett 面元近似，面元细分至等效边长 ≤12mm；
  影刃 10.5 万面 / 锐矛 47 万面 / 组合体 173 万面）。**标定**：金属球 r=150mm @10GHz，
  PO −11.50 dBsm vs 解析 πr² −11.51 dBsm，偏差 +0.00 dB。
- **矩阵**：3 对象（影刃 C2 / 锐矛 C1 / 组合体 SC_A）× 3 频率（8/10/12 GHz）× 3 材质
  （全金属 / 涂层−10dB / 涂层−15dB）× 方位角 ±90°（0°=鼻向，0.5° 步长）。
- **关键结果**（10 GHz）：影刃全金属鼻向峰值 18.5 dBsm、鼻向 ±15° 均值 3.4 dBsm（不达标）；
  −15dB 涂层后均值 −14.9 dBsm、超限角度 20%。锐矛/组合体鼻向峰值 48/53 dBsm——比影刃高
  30/35 dB，量化印证"解耦出隐身无人机"的战术价值。
- **输出**：`export/rcs/`（CSV 全数据 + 5 图：三状态对比 / 影刃材质 / 频率影响 / 极图 / 球标定）。
- **声明**：PO 高频近似，不含边缘绕射（PTD）；腔体贡献为上界估计；结果为设计评估级，
  认证需暗室缩比实测闭环。

### 6.1 真实环境修正（`rcs_realistic.py`，响应"未计尾焰/热表面/等离子体"评审）

- **修正 #22**：首跑误用收拢翼 `yr_uav.stl`（PARTS 主件，翼上折 90°）；正确对象为展开态

  捆绑段的散射更差、展开后更优，符合物理直觉。

### T2 气动 L/D 解析面元法（`aero_analytic.py` → `export/aero/`）
- 方法：牛顿冲击 Cp=2sin²θ 面元积分（法向全解析给定：剖面折线外法向/管面向径/平板定向），
  + 湍流摩阻 Cd_f=0.002·S_wet/A_ref + 底阻 Cd_b=0.12·S_base/A_ref；流向系力分解。
  弃用 STL 路径：布尔残留网格瑕疵（sc_c1 含非设计"墙面元"，S_wet 虚增一倍）不可用于气动画元。
- 标定：二维楔 牛顿 vs 精确斜激波 = 低估 24~43%（M6/M8，δ10–20°）——压差项系统性偏保守。
- 结果（α 扫描 0~20°）：**A′ 捆绑滑翔 max L/D=2.44 @ α≈14°（断言带 2.2–2.4 内 ✓）**；
  C1 锐矛 max L/D=2.04 @ α≈17°（未修正），按楔标定修正压差后 ≈2.6–2.8（断言带内）。
- 局限与结论：冲击理论升力为 α² 律，最优迎角（14–17°）显著高于方案设计点（5–7°）；
  方案低 α 高 L/D 依赖升力面线性项（前缘吸力/压缩升力），超出冲击法能力，R3 CFD 确认。

### T3 红外特征量级（`ir_estimate.py` → `export/ir/`）

- 结论：MWIR 为红外公约数（1450–2263K 部件 Wien 峰 1.3–2μm，尾部延伸入 MWIR）；
  红外探测距离（~20km）远超雷达对 −21dBsm 目标的探测距离——"雷达隐身≠红外隐身"
  有了量化注脚；对策页指向尾焰遮挡/冷却掺混/侧向辐射限制（未展开设计）。
