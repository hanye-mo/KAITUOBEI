## 0. 建模执行规约（GLM-5.3Flash 必读，先于一切建模动作）

### 0.1 角色与边界

你（GLM-5.3Flash）的角色是 **CAD 建模执行模型**：按本文档第 3、4 章的几何定义与参数表，用
Blender Python（bpy/bmesh，后台无界面执行）生成参数化模型并导出交付物。你**不做气动分析、
不修改设计**；一切数值以本文档为准。

### 0.2 八条铁律

1. **参数唯一来源**：`model/lib/params.py` 必须与本文档 §3.1 全局参数表逐项一致。**禁止自创、
   修改、四舍五入任何尺寸**。若发现参数矛盾或无法建模，写入 `MODELING_LOG.md` 的"变更申请"栏，
   并按保守方向（不改变外形特征尺寸）处理，不得静默改数。
2. **单位一律 mm**；导出 STL/3MF 不缩放。
3. **坐标系**（全局，即状态 A 组合体坐标系）：原点 = 锐矛头部顶点；**+X 指向机尾（下游）**；
   +Y 指向右舷；+Z 向上。各部件局部坐标系在 §3 中单独定义，装配时变换到全局系。
   Blender 默认 Z-up 右手系，直接沿用无需换轴；出图时"侧视"= 相机在 −Y 侧朝 +Y 看，
   "前视"= 相机在 −X 侧（锐矛鼻尖前方）朝 +X 看。
4. **零依赖、脚本可重建**：只使用 Blender（3.6 LTS 或 4.x）自带的 `bpy`、`bmesh`、
   `mathutils` 与内建修改器/布尔（EXACT 解算器），**不安装任何第三方插件、不联网**。
   全部几何由 Python 脚本生成——`.blend` 文件只是构建快照，修改参数后重跑
   `build_all.py` 即整体重建；**禁止在 GUI 中手工编辑几何**（查看/渲染不受限）。
   统一后台执行入口：`blender --background --factory-startup --python build_all.py -- <step>`。
5. **分步执行**：严格按 §4.3 的 S1→S7 顺序；每步先跑该步"自检命令"，自检通过才进入下一步。
6. **失败处理**：单步失败重试 ≤2 次；仍失败则按 §0.3 降级规则处理并记录。**降级只能简化几何细节，
   永远不能改特征尺寸**。
7. **命名规范**：脚本文件全小写下划线；构建函数 `build_` 前缀；Blender 物体名
   `RM_/YR_/YW_/BR_/FA_/BO_` 前缀；变量名与 §3.1 表完全一致。
8. **全程日志**：每步在 `MODELING_LOG.md` 追加记录（模板见 §0.4），无论成功、失败、降级。

### 0.3 降级规则表

| 若失败 | 降级方案 |
|---|---|
| `bridge_loops` 放样报错/破面 | 站位间线性加密 1 倍；仍失败则截面点数 24→16 |
| 前缘钝化圆柱链破面 | 改用 UV 球链（r 同值），允许轻微竹节 |
| Solidify 抽壳 3mm 失败 | 输出实体罩（外观不受影响），日志注明"壁厚未抽" |
| 布尔运算失败/过慢（EXACT） | 改 `Fast` 解算器重试；仍失败则孔/格胞改为贴面刻线薄片 |
| EEVEE 渲染失败 | 改用 Workbench 引擎出图（Solid 平涂色，PNG 交付不受影响） |
| 3MF 导出器缺失（老版本） | 记降级，交 STL + BLEND 替代 |
| 任何尺寸自检超差（>±2mm） | 停止该步并重做，不许放行 |

## 1. 系统总体设计

### 1.1 任务与作战概念（摘要）

由轰-6N 防区外投放"迅雷"组合体（"锐矛"高超声速乘波体导弹 + 骑乘于其上表面的"影刃"变构无人机，
经"共生式捆绑"连接、由一体化整流罩包裹），经助推—滑翔（钱学森弹道）投送至目标区；
末段动态解耦后，锐矛以 M8 高速突击"破甲"，影刃以 M6.2 巡航"致盲/清扫"，形成协同打击群。
详细作战想定见《背景综述》，本方案只定义飞行器本体。

## 2. 三状态空气动力学设计

### 2.1 设计点汇总

| 状态 | 设计点 | 关键要求 |
|---|---|---|
| A 组合态（助推段） | M0.9–4.1，H 11–27 km，max-q M1.8/14 km/42 kPa | 可控、低跨声速阻力增量、捆绑不分离 |
| A′ 捆绑滑翔态 | M6.1/33 km 巡航滑翔，α 2–3°，q≈19 kPa | L/D≥2.2，乘波下表面不受污染 |
| B 分离过程 | M6.0/35 km，q≈13 kPa，\|α\|≤2° | 无感分离：姿态角偏差 ≤1.5°、角速率 ≤2°/s、全程无再接触 |
| C1 锐矛单独 | M8/38 km 巡航冲刺，α≈5°，q≈15 kPa | L/D≈2.6–2.8，末端 ≥12 g，LE 平衡温度 ≤2000 ℃ |
| C2 影刃单独 | M6.2/31 km 准巡航（微下滑 γ≈−1.5°），α 8–10°，q≈27 kPa | 冲压 8 kN 推阻平衡，L/D≈2.8，RCS<0.008 ㎡ |

### 2.2 状态 A：分离前整体

**2.2.1 气动共生布局（捆绑一体化）**
- 捆绑全部位于锐矛**上侧**：乘波体下表面（z=0 平面 + 附体激波）不被任何支架/罩污染，
  保证滑翔段升阻特性；这是"上骑式"布局相对侧挂/腹挂的核心优势。
- 整流罩前体为**幂律尖拱顶线**（指数 0.6，§3.4.3）+ 尖劈侧缘，与锐矛上表面构成收缩通道，
  捆绑段上表面局部增压：设计意图为补偿加装罩后的纵向压心后移（待 CFD 验证）。
- 罩侧壁沿锐矛前缘线上包（§3.4.2），避免在组合体最大宽度处产生台阶分离。
- 4×Φ20 泄压孔（轴后倾 30°）防止捆绑腔内外压差撕裂罩体并在抛罩时提供破腔流。

**2.2.2 跨/超声速与最大动压点**
- 投放 M0.85→1.8 为阻力敏感区：组合态 CD0（A_ref=0.636 m²）预估 M0.9 ≈0.85、M1.8 ≈0.55、
  M4 ≈0.45（0 轮工程估算，待修正）。
- 助推段攻角程序 ≤4°，侧滑 ≤2°；整流罩顶线与栅格舵偏转（±15°）满足铰链矩限制。
- max-q（M1.8/14 km/42 kPa）为结构载荷与舵效校核点。

**2.2.3 稳定与操纵（助推段）**
- 纵向静稳定裕度目标 **+1.0~1.5 倍助推器直径（0.9 m）** @max-q，由尾部 4×栅格舵（X 布置，45° 起）保证；
  滚转由栅格舵差动；推力矢量控制（摆动喷管 ±5°）作俯仰/偏航主控。
- 栅格舵在 M1.8–4 具良好亚跨超特性，铰链矩小、响应快（<50 ms），满足捆绑体大惯量控制。

**2.2.4 第一次分离：助推器抛离（A→A′）**
- 条件：MECO 后 2 s，M4.1/27 km/q≈28 kPa，α≈0°。
- 方式：环形爆炸螺栓（24×M8 预断）+ 4×分离弹簧（各 2.5 kN×120 mm），轴向分离速度 ≥1.5 m/s。
- 助推器燃尽后空心化、质心后移 → 静不稳定自然低头翻转尾坠，不追撞；判据：0–3 s 内
  最小轴向间隙 ≥0.3 倍弹径（270 mm），组合体攻角扰动 ≤1°。

**2.2.5 捆绑滑翔态（A′，钱学森弹道）**
- 分离质量 3420 kg；M6.1/33 km：q≈19 kPa，平衡升力需 CL≈0.30 → 配平 α≈7°，L/D≈2.2–2.4（含罩）。
- 跳跃滑翔窗口 30–38 km：上限受翼载/升力限制，下限受气动热与罩驻点温度（≤1870 ℃）限制。
- 纵向静稳定裕度 +2~4% L；横航向由影刃收拢翼（上折立尾效应）+ 锐矛翼梢小翼联合提供。

### 2.3 状态 B：分离时（末段解耦，核心创新环节）

**2.3.1 分离窗口**：M5.8–6.2；H=33–38 km；q=10–16 kPa；|α|≤2°；|β|≤1.5°；角速率 ≤3°/s。

**2.3.2 分离时序（设计值）**

| 时刻 (s) | 动作 | 参数 | 判据 |
|---|---|---|---|
| T−2.0 | 预偏置 | 舵面/RCS 归零补偿，飞控转入分离模态 | 姿态角速率 ≤1°/s |
| T0 | 电磁主解锁 | 10 kN，0.05 s 行程 15 mm | 若 0.06 s 未反馈→烟火备份自动触发 |
| T+0.05 | 整流罩两瓣侧上抛 | 火工作动筒 2×1.2 kN，0.2 s 翻转 >35° | 瓣体不得进入展翼扫掠体 |
| T+0.05 | 弹簧导离 | 4×3 kN×150 mm，推力方向 15° 侧上偏置；**合力偏心 ≤3 mm（R1.7，6-DOF 仿真：偏心 10 mm 最坏工况姿态偏差 4.99° 超判据；≤3 mm + RCS 预偏置为 0.45°/2.5°/s 收敛）** | 影刃 Δv≈1.2 m/s，侧/上分量比 0.97/0.26 |
| T+0.3 | 影刃外翼展开完成 | 90°→0°，火工+气动锁；35° 为中间检查位 | 展翼惯量突变由 RCS 预偏吸收 |
| T+0.8 | 超燃冲压点火 | 预燃室式，启动马赫数余量 ≥0.3 | M6.0≥启动边界 |
| T+3.2 | 锐矛脉冲 2 点火 | **R1.7 时序修订（原 T+1.0）**：6-DOF 仿真实测 30 m 间距于 T+3.25 s 到达（弹簧 Δv 1.2 m/s + 加速差 17 m/s²）；羽流安全在点火前即由侧距保证（T+1.0s 时侧距 1.11 m ≥0.45 m 判据） | 点火时轴向间距 >30 m |
| T+3.5 | 影刃转入巡航姿态 | α 8–10°，微下滑 | 姿态角偏差累计 ≤1.5° |

**2.3.3 干扰与防碰撞判据**
- 分离机构公差（R1.7 新增）：解锁弹簧合力偏心 ≤3 mm；RCS 于 T−2.0 s 预偏置 50 N 对
  预期扰动方向（6-DOF 仿真依据：sep6dof.py，10 mm 最坏偏心姿态偏差 4.99°/角速率
  8.3°/s 超限；3 mm + 预偏置为 0.45°/初始 2.5°/s，1.4 s 内收敛 <0.1°）。
- 影刃退出包络：0–1.0 s 两体最小间隙 ≥0.2 m（任意方向）；相对轨迹位于锐矛轴线下/上方 ±20°
  锥内无交点。
- 激波干扰：影刃（及其展开翼尖）在 T+0.3 前不得进入锐矛头部激波锥（M6 半锥角 μ=asin(1/6)≈9.6°，
  从锐矛鼻尖起量）；整流罩瓣抛离方向避开该锥。
- 羽流干扰：脉冲 2 喷管羽流扩张半角按 ≤15° 校核，点火时影刃在其外的侧向距离 ≥0.5×弹径（450 mm）。
- 变构"无感"指标：展翼 0.3 s 内滚转扰动 ≤10°（RCS 6×50 N + 外翼差动阻尼抑制），角速率 ≤2°/s。

### 2.4 状态 C1：锐矛单独（M8 高速突击）

**2.4.1 乘波体外形生成（设计原理）**
- 基准流场：M8、半锥角 12° 的尖锥绕流；前缘线（后掠 74°）由锥面流线追踪生成，下表面为贴体
  压缩面，上表面为自由流面（实际放宽为幂律鼓背，见 §3.2）。
- 容积改型：为容纳 500 kg 战斗部 + 1500 kg 推进剂，背部加厚，容积效率 η≈V/S^1.5≈0.19
  （纯乘波体 0.05–0.08），代价约 8% L/D——攻击型 HGV 的合理取舍。
- 前缘钝化 r=18 mm（±2）：M8/38 km 驻点热流 ≈1280 kW/m²，辐射平衡温度 ≈1990 ℃ ≤ 碳陶 2000 ℃；
  M8 段热浸时间限制 ≤60 s。

**2.4.2 气动性能预估（修正牛顿/切楔工程估算，置信度低，待 CFD）**

### 2.5 状态 C2：影刃单独（M6.2 隐身巡航）

**2.5.1 布局**：扁平融合体飞翼（尖劈侧棱 + 幂律上表面）+ 根部顺流铰链变后掠外翼

**2.5.2 隐身设计原则**（目标 RCS<0.008 ㎡，X 波段）：


- 物体命名前缀：`RM_`（锐矛）/`YR_`（影刃机身）/`YW_`（外翼）/`BR_`（支架）/`FA_`（罩）/

  `SC_C1`、`SC_C2`。
- **放样原语**（放 `lib/profiles.py` 或公共段，所有站位体一律用它）：
  ```python
  import bmesh
  def ring_edges(bm, verts):        # 截面环首尾闭合
      n = len(verts)
      return [bm.edges.new((verts[i], verts[(i + 1) % n])) for i in range(n)]
  def loft(sections, name="loft"):  # sections: 逐站位截面点列 [(x,y,z), ...]
      bm = bmesh.new()
      rings = [[bm.verts.new(p) for p in sec] for sec in sections]
      edges = [ring_edges(bm, r) for r in rings]
      for a, b in zip(edges, edges[1:]):
          bmesh.ops.bridge_loops(bm, edges=a + b)
      me = bpy.data.meshes.new(name); bm.to_mesh(me); bm.free()
      return me                     # 调用方建 object 并 link 进目标 Collection
  ```
- **布尔原语**：Union/Difference 一律 `modifier Boolean`，`solver='EXACT'`，用后 Apply
  （保持物体为最终网格，不留修改器栈，便于 STL 导出与 bbox 自检）。

### 4.3 分步任务（每步含自检，通过才进下一步）

**S1 参数与截面函数**
- 产出：`lib/params.py`（§3.1 全表逐项写入，变量名一致）、`lib/profiles.py`：
  ```python
  def arch_pts(s, h, n=20, p=2.2, q=0.75):
      """超椭圆拱顶截面（底平 z=0）：底边(左→右) + 顶弧(右→左, 去重端点)，返回 2D 点列"""
      pts = [[-s + 2.0 * s * i / (2 * n), 0.0] for i in range(2 * n + 1)]
      pts += [[s * (1 - 2.0 * i / n),
               h * (1 - abs(1 - 2.0 * i / n) ** p) ** q] for i in range(1, n)]
      return pts
  ```
  （允许实现细节不同，但每站位截面必须为"平底+拱顶凸形"、端点闭合无重复点、无自交。）
- 自检：`python lib/profiles.py`（纯 Python，无需 Blender）打印各站位截面积，应
  ≈0.736·(2s·h)（±15% 内）。

**S2 锐矛**

  见下）→ `loft()` 一次放样；鼻尖 r=18 UV 球（32 段）Boolean UNION。
- 平台削平：在生成站位截面时将顶弧 z clamp 到 `h(x)−45`（区间 1600–4000 内），端部 100 mm
  线性过渡（对 clamp 值做线性插值，不在放样后修网格）。

**S3 影刃**
- 机身同 S2（底平 z=0、顶弧 p=2.4/q=0.8、鼻尖 r=12）；进气道楔/唇口内凹/SERN 斜面用
  Boolean 加减；双外倾垂尾=梯形板（根弦 400 于 x_loc∈[1750,2150]、y=±430、展长 260、外倾 40°）。
- 外翼 `builders/wing_panel.py`（六边形翼型，根弦 460/尖弦 170/展长 420/LE 后掠 65°），
  三姿态用同一网格 + 铰链矩阵：
  ```python
  from math import radians
  from mathutils import Matrix
  def wing_matrix(fold_deg, side=+1):
      # 铰线：过 (y=650·side, z=95) 的 X 平行轴；折角 fold：0 部署 / 35 中间 / 90 收拢
      T0 = Matrix.Translation((1250, 650 * side, 95))      # 局部翼原点(根前缘) → 铰线位
      R  = Matrix.Rotation(radians(fold_deg) * side, 4, 'X')  # 绕 X 平行轴上折 +Y→+Z
      return T0 @ R
  # 右翼 = 左翼网格 mirror Y 后按 side 取列/旋向，收拢翼尖落于 y≈650、z_loc≈515
  ```

  z_loc=95+420），全局 Z[575…≈1090]；部署态翼尖 y_loc=±1070（650+420）、翼尖 x_loc≤2321。
