# 迅雷 · 协同高超声速突击系统

> 第七届"航天四部开拓杯"未来飞行器设计大赛 参赛项目
> 参赛队伍：清华大学笃实书院（2 名大二 + 1 名大一学生）｜主要成员：杨逸希
> 文档版本：R1（概念设计基线）｜更新日期：2026-10-01

---

## 1. 项目一句话

将 **"锐矛"高超声速乘波体导弹** 与 **"影刃"高超声速变构无人机** 以 **"共生式捆绑"** 融为一体：
**捆绑时气动融一体、分离时无感脱开、分离后一快一巧协同作战**——变"单枚突击"为"体系突击"。

## 2. 系统概念

```
                ┌────────────────────────────────────────────────┐
                │  状态A 分离前整体（投放→助推→捆绑滑翔）           │
                │                                                │
   轰-6N ──投放──► [整流罩 ─ 影刃(翼收拢) 骑乘于 锐矛 上表面] + [共推助推器]
                │        └────── 共生连接器（双点L型支架×2）──────┘    │
                └───────────────────────┬────────────────────────┘
                                        │ 末段 M6.0 / H35km 解耦
                ┌───────────────────────┴────────────────────────┐
                │  状态B 分离时（T+0 ~ T+1.3s）                     │
                │  整流罩两瓣抛离 → 电磁/烟火双冗余解锁 → 弹簧导离    │
                │  → 影刃外翼0.3s展开(65°后掠) → 超燃冲压0.8s点火    │
                └───────────────────────┬────────────────────────┘
                        ┌───────────────┴────────────────┐
                        ▼                                ▼
        ┌───────────────────────────┐   ┌───────────────────────────┐
        │ 状态C1 锐矛（单独）          │   │ 状态C2 影刃（单独）         │
        │ 脉冲2加力 6→8Ma(H38km)     │   │ 超燃冲压 8kN 巡航 M6.2     │
        │ 高速突击"破甲"，末端≥12g机动 │   │ 干扰/侦察/补刀"致盲+清扫"   │
        └───────────────────────────┘   └───────────────────────────┘
```

**协同战术**：导弹突击+无人机诱骗（前出干扰、模拟信号饱和敌防空）｜导弹破门+无人机清扫（毁伤评估、猎杀残余单元）。

## 5. 建模交接说明（如何交给 GLM-5.3Flash）

《建模方案》已按"小参数模型可逐步执行"的方式编写：**全参数单一来源表、逐件建模配方（含
Blender Python 代码骨架）、分步任务 S1–S7、每步验收自检、失败降级规则**。交接时使用如下提示词模板：

```text
你是 CAD 建模执行模型，使用 Blender（bpy/bmesh，后台无界面执行）。请打开并严格遵循《建模方案.md》：
1. 先通读第 0 章"建模执行规约"和第 3.1 节全局参数表——参数表是唯一数值来源，禁止自创或修改任何尺寸；
2. 按第 4.3 节顺序执行 S1→S7，统一入口 blender --background --factory-startup --python build_all.py -- <step>，
   每完成一步先跑 check.py 自检，通过后再进入下一步；
3. 只用 Blender 自带 bpy/bmesh/布尔（EXACT），不装第三方插件；单位 mm，坐标系/命名按规约执行；
   全部几何由脚本生成，禁止 GUI 手工编辑；
4. 每步结果（成功/失败/降级）写入 MODELING_LOG.md；
5. 最终交付 model/ 全部脚本 + thunder.blend + export/ 的 STL/3MF/PNG/MP4 + 已填写的尺寸自检表。
现在从 S1 开始。
```

**人工检查要点**（团队收到模型后）：对照《建模方案》§4.6 验收清单抽检关键尺寸（脚本
`check.py` 自动比对）；查看 MODELING_LOG.md 是否有未决降级项；渲染图三视图与分离动画 MP4 是否齐全。
